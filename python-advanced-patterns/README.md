# Python Advanced Patterns

This repository demonstrates production-grade Python patterns including:

- Function decorators for logging and timing
- Generator-based streaming
- Clean separation of concerns
- Extensible architecture for FastAPI and async workflows

## Structure

- `decorators/` – reusable decorators
- `generators/` – streaming generators
- `examples/` – runnable demos

## Run Examples

```bash
python examples/demo_decorator.py
python examples/demo_generator.py
